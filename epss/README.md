# EPSS scores

Original publishers: FIRST EPSS Special Interest Group and Empirical Security.

`epss_scores-current.csv.gz` contains the current daily score/percentile snapshot.
The complete downloaded historical repository is retained locally as
`archives/empiricalsec--epss_scores.zip` with the original dated CSV files.

Official history: https://github.com/empiricalsec/epss_scores. Published history begins
on 2021-04-14. Model versions change over time; preserve each original score date
and model header when comparing historical scores. The large history archive is
excluded from ordinary Git commits.
